# 🌐 Personal Portfolio Website

A responsive, modern personal portfolio website built to showcase my projects, technical skills, resume, and experience as a software developer.

🔗 **Live Demo:** [View live site](https://suhanihub2403.github.io/Personal-Portfolio/)

---

## 🛠️ Built With

- **Frontend:** HTML5, CSS3, JavaScript
- **Styling:** Flexbox, Grid, Responsive Design (Mobile & Desktop friendly)
- **Deployment:** GitHub Pages

---

## ✨ Features

- **About Me:** Brief introduction and academic/professional background.
- **Projects Showcase:** Highlights of my development work with descriptions and links.
- **Skills Section:** Technical tools, languages, and competencies.
- **Resume Access:** Direct option to view or download my latest resume.
- **Contact Form / Social Links:** Easy ways to connect via LinkedIn, GitHub, and email.
